# Quarantine Games on Networks

Code, measured data and figures for *Quarantine Games on Networks: Beyond Epidemic Establishment* by Marco Antonio Amaral.

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24518324.svg)](https://doi.org/10.5281/zenodo.24518324)

## Reproduce the RC10 figures

Download [the self-contained scientific archive](reproducibility/rc10-s5e12.1/quarantine_games_network_rc10-s5e12.1.zip) and extract it to an empty folder. Follow its README with Python 3.12 and the pinned requirements. The archive includes a figure-by-figure index, measured data, the analysis code and all 17 vector assets used in the 11 main and five supplementary figures. The commands restore the archived graphics and independently redraw Figures 10, 11 and S5 from supplied observations. The seven checks and rendering commands were run on Windows. No new epidemics were simulated for this package.

Archive SHA-256: `bb05fd0fbec2a31b327ceb50a898009b8e8e30e4f85c3ca48378e3f996cb72b1`. The nested measured-data archive retains its independent version 1.0.0.

The root simulation and historical reconstruction entry points remain available. For RC9.5 instructions and historical data dependencies, consult the [prior version](https://github.com/AmaralMA42/quarantine_games_network/tree/rc9.5-p10.4-authorial-20261106). The RC10 archive contains its own entry points and dependencies.
